PIKPAK AUTO SAVE v3.0 THỬ NGHIỆM - giao diện web trong cửa sổ app
=================================================================

CÁCH DÙNG
  1. Tắt bản v2.5 (chuột phải icon ở khay đồng hồ -> Thoát).
  2. Chép file "PikPak Auto Save v3 (thu nghiem).exe" vào CÙNG thư mục với "PikPak Auto Save.exe" (bản v2.5).
     Bản thử dùng chung thư mục Data (thư mục phim, Danh sách đã có, lịch sử, tài khoản PikPak, rclone.exe).
  3. Chạy file exe bản thử. Windows 10/11 đã có sẵn Edge WebView2 nên không cần cài thêm.
     Nếu máy thiếu WebView2: tải "Evergreen Bootstrapper" tại https://developer.microsoft.com/microsoft-edge/webview2/

ĐÃ LÀM TRONG BẢN THỬ
  - Tab Quét & Tải đầy đủ: Quét, Quét & Tải, Dừng, chọn dòng, Tải mục đã chọn, Đánh dấu đã có, tìm, lọc,
    sắp xếp cột, nhấp đúp mở file / nguồn, 3 thanh tải sọc chạy, nhật ký.
  - Cột trái: thẻ "Mọi thứ hoạt động tốt / Có N mục cần xử lý" (bấm để xem), bảng đèn trạng thái:
    PikPak (email, VIP, dung lượng - bấm để kiểm tra lại kết nối), rclone, Tự quét (bấm để bật / tắt, chọn số phút),
    Đang tải, Sao lưu (bấm để sao lưu ngay), Lỗi (bấm để mở + copy báo cáo lỗi).
  - Tự quét theo lịch, kiểm tra trước khi tải, tự tải lại file lỗi, sao lưu lên PikPak sau khi tải xong:
    dùng lại nguyên phần lõi của v2.5.
  - Nút "◐ Giao diện": đổi sáng / tối.
  - Tab Lịch sử, Thư mục phim, Cài đặt: CHỈ XEM.

CHƯA CÓ (vẫn dùng bản v2.5)
  - Thêm / sửa / duyệt thư mục phim, đổi cài đặt, tài khoản PikPak, tải rclone, mật khẩu admin.
  - Thu nhỏ xuống khay đồng hồ, chạy cùng Windows, thông báo Windows, nút Cập nhật.
  - Đóng cửa sổ bản thử là tắt hẳn tool (không chạy nền).

LƯU Ý: không mở cùng lúc bản v2.5 và bản thử - 2 bản ghi chung dữ liệu. Bản thử tự báo nếu thấy v2.5 đang mở.
